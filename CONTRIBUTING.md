# 🤝 Katkıda Bulunma Rehberi

Öncelikle, **LinkedIn Post Generator™**'a katkıda bulunmayı düşündüğünüz
için teşekkür ederiz. Bu, sizin de artık *"open source ekosistemine değer
katan bir thought leader"* olduğunuz anlamına geliyor. Bunu LinkedIn'de
paylaşmayı unutmayın (bu araçla, tabii ki).

## 📜 Katkı Kuralları

1. **Her PR açıklaması en az 3 buzzword içermelidir.**
   Örnek: "Bu PR, *scalability*, *observability* ve *developer experience*
   alanlarında **quantum leap** sağlıyor."

2. **Commit mesajlarınız emoji ile başlamalıdır.**
   `git commit -m "🚀 feat: synergy katmanını optimize ettim"`
   (Ne yaptığınız önemli değil, emoji önemli.)

3. **PR'ınızı açmadan önce LinkedIn'de "big announcement" olarak duyurun.**
   Merge edilmeden önce duyurmak, *radical transparency*'nin bir gereğidir.

4. **Kod incelemesi sırasında en az bir kez "let's circle back on this"
   yazmalısınız.**

## 🐛 Bug Bildirimi

Bir bug bulduysanız, lütfen önce LinkedIn'de "Bugün production'da ilginç
bir keşif yaptım 🧵" başlıklı bir thread açın, sonra issue oluşturun.

## 🏗️ Geliştirme Ortamı Kurulumu

```bash
git clone https://github.com/dvicewashere/zattiri-zort-zort.git
cd zattiri-zort-zort
python generator.py --help
```

Bağımlılık yönetimi yok, çünkü gerçek **10x developer**'lar buna ihtiyaç duymaz.

## 🎖️ Katkıda Bulunanlar Onur Listesi

Katkınız merge edildiğinde, isminiz bu README'ye **"Founding Contributor"**
olarak eklenir ve LinkedIn profilinize "Open Source Maintainer" unvanını
ekleme hakkı kazanırsınız (unvanı biz vermiyoruz, siz ekliyorsunuz, ama
kimse sormuyor).
